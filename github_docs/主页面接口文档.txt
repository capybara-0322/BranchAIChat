

# 会话相关接口

## 创建会话

**基本信息**
Path： `/api/sessions/create`
Method： **POST**
接口描述：新建一个空会话（生成 `sid`），用于后续承载分支对话。

**请求参数**

**Headers**

| 参数名称         | 参数值              | 是否必须 | 示例 | 备注 |
| ------------ | ---------------- | ---- | -- | -- |
| Content-Type | application/json | 是    |    |    |
| Authorization | Bearer <jwt>|	是 |    | 用户身份认证

**Body**

| 名称    | 类型     | 是否必须 | 默认值 | 备注   | 其他信息 |
| ----- | ------ | ---- | --- | ---- | ---- |
| title | string | 否    |     | 会话标题 |      |

**返回数据**

| 名称                    | 类型              | 是否必须 | 默认值 | 备注               | 其他信息                       |
| --------------------- | --------------- | ---- | --- | ---------------- | -------------------------- |
| code                  | integer         | 必须   |     | 状态码              | format: int32              |
| msg                   | string | null  | 非必须  |     | 提示信息             |                            |
| data                  | object          | 必须   |     | 会话对象             |                            |
| ├─ sid                | string          | 必须   |     | 会话ID             | format: uuid               |
| ├─ title              | string          | 必须   |     | 标题               |                            |
| ├─ created_at        | string          | 必须   |     | 创建时间             | format: date-time(ISO8601) |
| ├─ updated_at        | string          | 必须   |     | 最近更新时间           | format: date-time          |
| ├─ last_active_tid  | integer | null | 非必须  |     | 最近活跃的本会话tid      | format: int64              |
| ├─ last_active_tuid | string | null  | 非必须  |     | 最近活跃的全局turn uuid | format: uuid               |
| ├─ turn_count        | integer         | 必须   | 0   | 节点数量             | format: int32              |

---

## 会话分页查询

**基本信息**
Path： `/api/v1/sessions/page`
Method： **GET**
接口描述：按最近更新时间倒序分页列出历史会话。

**请求参数**

**Headers**
| Authorization | Bearer <jwt>|	是 |    | 用户身份认证


**Query**

| 参数名称     | 是否必须 | 示例     | 备注          |
| -------- | ---- | ------ | ----------- |
| title    | 否    | “产品讨论” | 标题模糊匹配      |
| page     | 是    | 1      | 页码（从1开始）    |
| pageSize | 是    | 20     | 每页记录数（≤100） |

**返回数据**

| 名称                       | 类型             | 是否必须 | 默认值 | 备注                |
| ------------------------ | -------------- | ---- | --- | ----------------- |
| code                     | number         | 必须   |     |                   |
| msg                      | null | string | 非必须  |     |                   |
| data                     | object         | 必须   |     |                   |
| ├─ total                 | number         | 必须   |     | 总数                |
| ├─ records               | object []     | 必须   |     | 会话记录列表            |
| │  ├─ sid                | string         | 必须   |     | format: uuid      |
| │  ├─ title              | string         | 必须   |     |                   |
| │  ├─ created_at        | string         | 必须   |     | format: date-time |
| │  ├─ updated_at        | string         | 必须   |     | format: date-time |
| │  ├─ last_active_tid  | number | null | 非必须  |     | format: int64     |
| │  ├─ last_active_tuid | string | null | 非必须  |     | format: uuid      |
| │  ├─ turn_count        | number         | 必须   |     |                   |

# 节点/分支（Turn）相关接口

## 创建节点（从父节点分叉或作为根）

**基本信息**
Path： `/api/v1/sessions/{sid}/turns`
Method： **POST**
接口描述：在会话中创建一个新节点（用户消息 + 可选AI摘要），若传 `parent_tid` 则挂到对应父节点下。

**请求参数**

**Headers**

| 参数名称         | 参数值              | 是否必须 |
| ------------ | ---------------- | ---- |
| Content-Type | application/json | 是    |
| Authorization | Bearer <jwt>|	是 |    | 用户身份认证

**Path**

| 参数名称 | 是否必须 | 示例      | 备注   |
| ---- | ---- | ------- | ---- |
| sid  | 是    | `8b3c…` | 会话ID |

**Body**

| 名称          | 类型      | 是否必须 | 默认值 | 备注               | 其他信息          |
| ----------- | ------- | ---- | --- | ---------------- | ------------- |
| parent_tid | integer | 否    |     | 父节点tid；不传=作为根子节点 | format: int64 |
| user_json  | object  | 必须   |     | 用户消息摘要/内容        | 建议压缩          |
| ai_json    | object  | 否    |     | AI回复摘要/内容        | 建议压缩          |

**返回数据**

| 名称                    | 类型              | 是否必须 | 备注                |                  |
| --------------------- | --------------- | ---- | ----------------- | ---------------- |
| code                  | integer         | 必须   |                   |                  |
| msg                   | string | null  | 非必须  |                   |                  |
| data                  | object          | 必须   | 新建的节点             |                  |
| ├─ sid                | string          | 必须   | format: uuid      |                  |
| ├─ tid                | integer         | 必须   | 会话内自增             | format: int64    |
| ├─ tuid               | string          | 必须   | 全局UUID            | format: uuid     |
| ├─ parent_tid        | integer | null | 必须   | 根节点时为 null        | format: int64    |
| ├─ user_json         | object          | 必须   |                   |                  |
| ├─ ai_json           | object | null  | 非必须  |                   |                  |
| ├─ created_at        | string          | 必须   | format: date-time |                  |
| ├─ last_accessed_at | string          | 必须   | format: date-time |                  |
| ├─ children_tids     | array(integer)  | 必须   | 初始空数组             | format: int64[] |

# 一体式对话接口（创建节点并生成AI回复）

## 发消息并生成AI回复

**基本信息**
Path： `/api/v1/sessions/{sid}/chat`
Method： **POST**
接口描述：从 `parent_tid`（可选）继续或分叉，发送用户消息，服务端生成 AI 回复，并以一个新节点写入树中。

请求参数

Headers

参数名称	参数值	是否必须	示例	备注
Content-Type	application/json	是		
Accept	text/event-stream	是		指定 SSE 输出
Authorization	Bearer <jwt>	是		用户身份认证

Path

参数名称	是否必须	示例	备注
sid	是	8b3c…	会话ID

Body

名称	类型	是否必须	默认值	备注	其他信息
parent_tid	integer	否		继续/分叉的父节点	format: int64
user_json	object	必须		用户消息内容	
gen_config	object	否		生成参数（温度、最大tokens等）	
├─ temperature	number	否	0.7		
├─ max_tokens	integer	否	1024		
stream_options	object	否		流控制选项	
├─ include_usage	boolean	否	false	是否在尾事件附带 token 用量汇总	
├─ heartbeat_sec	integer	否	10	心跳事件间隔（秒）	
client_event_id	string	否		客户端自定义ID，便于去重/追踪	

返回数据

⚠️ 注意：本接口返回为 SSE事件流，而非一次性 JSON。下面列出主要事件类型及 data 格式。

事件类型	data示例	说明
chunk	{"sid":"…","gen_id":"…","index":0,"delta":"今","finish_reason":null}	模型增量输出
tool_call	{"gen_id":"…","call_id":"…","name":"search","arguments":{"q":"…"}}	工具调用事件
usage	{"gen_id":"…","prompt_tokens":123,"completion_tokens":456,"total_tokens":579}	token 用量统计
ping	{}	心跳事件
error	{"code":500,"msg":"provider timeout","gen_id":"…"}	错误事件，流立即终止
done	{"code":1,"msg":null,"data":{"sid":"…","tid":18,"tuid":"…","parent_tid":12,"user_json":{…},"ai_json":{"text":"完整汇总","segments":[…]},"created_at":"…","last_accessed_at":"…","children_tids":[]}}	最终收尾事件，提供完整 turn 对象
